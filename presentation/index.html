Problem Discovery & Task Formulation
Business Problem & Machine Learning Task
Rubric Criteria 1 & 8
⚠️ Real-World Problem
  • Noisy Descriptions: Raw bank strings are cryptic (e.g. [debit] PUBLIX 7860, MTG PMT PENFED CU).
  • Rule Breakdown: Manual regex tables fail as thousands of new merchant formats appear.
  • Cost & Delay: Manual transaction tagging does not scale for millions of active cardholders.
🎯 ML Formulation
  • User: Digital banking app users & personal budgeting dashboards.
  • Input: Raw description string + optional transaction flag.
  • Output: 1 of 17 spending categories + calibrated probability.
  • Safety Gate: Low-confidence or unrecognized strings flagged needs_review.
📊 17-Category Taxonomy
  • Living: Groceries, Mortgage, Utilities, Gas/Automotive.
  • Discretionary: Restaurants, Shopping, Entertainment, Travel.
  • Financial: Income, Transfer, Fees, Financial Services, Subscriptions.
  • Balance: All 17 classes are equally critical for budgeting.
Data Gate & Provenance
Data Pipeline & Zero-Leakage Controls
Rubric Criteria 2 & 3
📦 Dataset Architecture & Cleaning
  • Dataset: DoDataThings/us-bank-transaction-categories-v2 (MIT License, Hugging Face).
  • De-Duplication (DQ-01): 22,298 duplicate rows (32.8%) dropped before splitting (68,000 → 45,692 unique descriptions).
  • Ambiguity Removal (DQ-02): 5 conflicting labeled rows dropped.
  • ID Normalization (DQ-03): Store #s, ZIPs, and reference IDs converted to <num> to prevent fingerprinting.
🛡️ Leakage Controls & Fit Boundary
  • Stratified Split: 70% Train (31,984), 15% Valid (6,854), 15% Protected Test (6,854).
  • Strict Fit Boundary: Vectorizer vocabulary and IDF weights fit strictly on Train split.
  • Boundary Test: test_data_gate.py confirms 0 descriptions appear across splits.
  • Protected Test: Accessed exactly once in finalize.py after candidate freeze.
Model Exploration & Sweep
Model Comparison & Key Empirical Finding
Rubric Criteria 3 & 4
Model / Architecture Feature Setup Val Macro-F1 Calibrated Proba Decision Status
Naive Dummy Classifier Most Frequent Class 0.0094 No Baseline Floor
TF-IDF + Logistic Regression Word 1–2 n-grams 0.9960 Yes (predict_proba) SELECTED WINNER
TF-IDF + LinearSVC Char_wb 3–5 n-grams 0.9971 No Rejected (No Proba)
Sentence Transformers (MiniLM) 384-dim Dense Embeddings 0.9468 Yes Rejected (Worse & 40x Slow)
💡 Why Bag-of-Words Beat Transformers on Short Financial Strings
  • Financial discriminative signal is concentrated in specific lexical tokens (MTG PMT, DIR DEP, PUBLIX).
  • Dense embeddings blur exact token boundaries, lowering Macro-F1 to 0.9468 while adding 400MB dependencies.
  • Logistic Regression yields calibrated probabilities for confidence gating at <1ms latency and 1.2MB footprint.
Evaluation & Error Analysis
Protected Test Results & Honest Generalization
Rubric Criteria 4, 7 & 8
🏆 Protected Test Set (n=6,854)
  • Test Macro-F1: 0.9961 (>100x lift over baseline).
  • Test Accuracy: 99.55% | Top-3 Accuracy: 99.90%.
  • Per-Class Reliability: Strong across all 17 categories (lowest: Shopping 0.984, Groceries 0.986).
  • Confusion Pattern: Big-box merchants overlapping between Groceries and Shopping.
🔍 Unseen-Merchant Honest Slice (n=716)
  • Novel Merchant Slice: Test rows from merchants never seen during training.
  • Unseen Macro-F1: 0.9784 (~1.8% realistic drop).
  • Honest Takeaway: In-distribution scores are optimistic due to templating; the 0.9784 slice reflects true live-feed performance.
  • Mitigation: Out-of-vocabulary check triggers review rather than silent error.
